# Learning Path de Inteligência Artificial aplicada ao desenvolvimento de Software

Este repositório contém recursos e materiais de estudo para quem deseja aprender sobre Inteligência Artificial, incluindo conceitos teóricos, tutoriais práticos e projetos de exemplo.

## Motivação

Você deve estar se perguntando: por que mais um repositório com guias e materiais sobre Inteligência Artificial?

Assim como acontece com outros campos de conhecimento, encontramos uma grande quantidade de informações dispersas sobre Inteligência Artificial. Isso pode dificultar o aprendizado, especialmente para quem está começando. Nosso objetivo é organizar esses recursos de forma lógica e progressiva, facilitando o estudo e a aplicação prática dos conceitos.

Uma segunda motivação é o fato de que em muitos casos os materiais disponíveis abordam o assunto com frameworks e ferramentas específicas, sem fornecer uma compreensão sólida dos conceitos fundamentais. Nosso objetivo é começar pelos conceitos base e, a partir deles, avançar para a aplicação prática no desenvolvimento de software.

## Estrutura do Aprendizado

O curso está organizado em módulos, cada um abordando um aspecto específico da Inteligência Artificial aplicada ao desenvolvimento de software. Cada módulo contém:

- Material teórico resumido para compreensão dos conceitos - use se preferir um modelo de estudo guiado sobre os tópicos abordados.
- Gemini Notebook com todas as fontes e exemplos utilizados para estudo interativo - permitindo que você explore e aprenda de forma prática.
- Projetos de exemplo para consolidar o aprendizado - permitindo que você aplique os conceitos em situações reais. Para cada projeto fornecemos uma SKILL específica para revisar o resultado e orientar possíveis melhorias.
